# Cloud Bookstore

A bookstore web application built using Python and Flask.

## Features
- Browse books
- Customer signup and login
- Book ordering
- Order details
- Admin functionality
- AWS EC2 hosting
- Amazon RDS database integration
- Amazon S3 book cover images

## Technologies
- Python
- Flask
- MySQL / Amazon RDS
- Amazon EC2
- Amazon S3
- Git and GitHub

## Security
Database credentials and secret keys should be configured using environment variables.
Never commit passwords, secret keys, or AWS credentials to GitHub.
